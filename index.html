KYUURIQ ESP

Custom firmware for ESP32-WROOM-32. Built for experimentation, learning and hardware control.

View on GitHub Explore

Features

Wi-Fi

Connect the ESP32 to a local network and access the device over Wi-Fi.

Web Control

Control the device from a browser using a lightweight web interface.

GPIO

Designed to interact with external hardware through ESP32 GPIO pins.

System Info

Monitor memory, uptime, Wi-Fi state and other ESP32 information.
