KQ ESP

Custom local firmware platform for ESP32-WROOM-32. Built for experimentation, learning, hardware control and embedded development.

View on GitHub Explore KQ ESP Flasher

Features

Wi-Fi

Connect the ESP32 to a local network and access the device over Wi-Fi.

Local Web Control

Control the ESP32 from a browser through a local Web interface. No cloud server is required.

PWM

Control LED brightness using hardware PWM from 0% to 100%.

LED Modes

Solid, Blink, Fast Blink, Slow Blink, Pulse and Breathing modes.

Preferences

Device settings such as brightness, LED state and mode are stored persistently.

Serial Console

Control the device and inspect its state through the Serial interface.

OTA Updates

Upload new firmware to the ESP32 over the local Wi-Fi network.

System Info

Monitor free RAM, uptime, Wi-Fi signal and firmware version.
