# Установка KQ ESP — простая инструкция

Эта инструкция для обычных пользователей, без программирования. Нужен только
компьютер, кабель и плата ESP32-WROOM-32.

---

## 1. Что понадобится

- Плата **ESP32-WROOM-32** (обычный «девкит» с USB-портом).
- USB-кабель **с передачей данных** (не «только зарядка»).
- Компьютер с браузером **Chrome, Edge или Opera** (Firefox/Safari веб-прошивку
  через браузер не поддерживают).
- Сеть Wi-Fi 2.4 ГГц (ESP32 не работает в 5 ГГц).

---

## 2. Прошивка через браузер (самый простой способ)

1. Открой в браузере страницу прошивальщика:

   **https://kyuuriq197.github.io/kyuuriq-esp32/flasher/**

2. Подключи плату к компьютеру по USB.

3. Нажми кнопку **Connect** и выбери порт платы (обычно `USB-SERIAL CH340` или
   `CP2102`). Если порт не появляется — установи драйвер (см. раздел 6).

4. Нажми **Erase** (стереть), затем **Install / Flash**.

5. Дождись надписи «Done». Плата перезагрузится.

> Если прошивка не идёт: зажми кнопку **BOOT** на плате, кратко нажми **EN/RST**,
> отпусти **BOOT** и повтори прошивку.

---

## 3. Первый запуск и настройка Wi-Fi (обязательно)

После прошивки плата не знает твой домашний Wi-Fi, поэтому запускает свой режим
настройки:

1. На телефоне или ноутбуке открой список Wi-Fi сетей.
2. Подключись к сети **`KQ-ESP-Setup`** (пароля нет).
3. Открой в браузере **http://192.168.4.1**
4. Введи название своего Wi-Fi (SSID) и пароль, нажми **Save & Reboot**.
5. Плата перезагрузится и подключится к твоей сети.

Wi-Fi данные сохраняются в памяти платы — вводить их повторно не нужно. Чтобы
сменить сеть, удерживай кнопку **BOOT** при включении (или залей прошивку заново).

---

## 4. Как открыть веб-интерфейс

Нужно узнать IP-адрес платы в твоей сети:

- **Способ А:** посмотри список устройств в роутере (приложение провайдера или
  страница роутера) — ищи устройство с именем `KQ ESP` / `Espressif`.
- **Способ Б (для гиков):** открой Serial-монитор в Arduino IDE на скорости
  **115200** — при загрузке там печатается `IP: 192.168.x.x`.

Открой этот IP в браузере:

- `http://<IP>/` — управление светодиодом (вкл/выкл, яркость, эффекты).
- `http://<IP>/menu` — **меню модулей**: WiFi Scan, I2C Finder, System Info.

На главной странице есть кнопка **Open Web Menu**.

---

## 5. Обновление прошивки по Wi-Fi (OTA)

Если плата уже прошита и подключена к сети, обновить её можно без USB:

1. Открой проект в **Arduino IDE** (файл `firmware/kq_esp32.ino`).
2. Установи в `firmware/secrets.h` свой Wi-Fi (см. раздел 7).
3. Меню **Tools → Port** покажет сетевой порт `kq-esp32 at 192.168.x.x`.
4. Нажми **Upload** — прошивка уйдёт по Wi-Fi.

---

## 6. Драйвер USB (если порт не виден)

Большинство плат использует чип **CH340** или **CP2102**:

- **Windows:** скачай драйвер CH340 (или CP2102 / Silicon Labs CP210x) и установи,
  затем переподключи плату.
- **Linux:** обычно работает сразу. При ошибке доступа добавь себя в группу:
  ```bash
  sudo usermod -aG uucp,lock $USER
  ```
  и перезайди в систему.
- **macOS:** для CH340 нужен драйвер WCH, для CP2102 — Silicon Labs.

---

## 7. Сборка из исходников (для разработчиков)

1. Установи **Arduino IDE 2.x**.
2. В **Preferences → Additional Boards Manager URLs** добавь:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
3. **Boards Manager** → установи **esp32 by Espressif**.
4. Скопируй `firmware/secrets.example.h` в `firmware/secrets.h` и впиши свои Wi-Fi:
   ```cpp
   #define WIFI_SSID "МояСеть"
   #define WIFI_PASSWORD "мой_пароль"
   ```
   (файл `secrets.h` не попадёт в GitHub — он в `.gitignore`).
5. Открой `firmware/kq_esp32.ino`, выбери плату **ESP32 Dev Module**, порт и жми
   **Upload**.

---

## 8. Платы с экраном (меню на устройстве)

Модульное меню (WiFi / BLE / IR / GPIO / Tools) умеет рисоваться на экране, но
включается только если в проекте есть библиотека дисплея. Для плат с экраном
(ST7789) установи:

```
Adafruit GFX Library
Adafruit ST7735 and ST7789 Library
```

и пересобери — устройство загрузится прямо в меню (кнопки UP/DOWN/OK/BACK).

На плате **без экрана** ничего настраивать не нужно: меню просто не включается,
всё работает через веб-интерфейс.

---

## 9. Частые проблемы

| Проблема | Решение |
|---|---|
| Порт не появляется | другой USB-кабель, драйвер (раздел 6) |
| Прошивка не идёт | BOOT + RST (см. раздел 2), другой кабель/порт |
| Не подключается к Wi-Fi | только 2.4 ГГц; проверь логин/пароль; при сбое снова появится `KQ-ESP-Setup` |
| Не открывается веб | узнай IP платы в роутере (раздел 4) |
| Режим настройки не уходит | введён неверный пароль — подключись к `KQ-ESP-Setup` и введи заново |

---

## Безопасность

Никогда не публикуй название своей сети, пароль, токены и ключи. Файл
`firmware/secrets.h` содержит твои данные и не должен попадать в публичный
репозиторий.
